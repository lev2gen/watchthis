# Roadmap

Planned improvements for WatchThis. Order is indicative, not a promise.

## Near term
- [ ] Mobile vs desktop rendering comparison (Googlebot smartphone user agent)
- [ ] Export check results as PDF / JSON
- [ ] Shareable permalink for every check result

## Mid term
- [ ] Bulk checks — paste a list of URLs or a sitemap.xml
- [ ] Scheduled re-checks with email alerts when the render diff changes
- [ ] Public REST API with API keys

## Ideas / exploring
- [ ] Chrome extension for one-click checks from any page
- [ ] Historical trend view per URL
- [ ] Comparison against Google Search Console rendering

Have a suggestion? [Open an issue](https://github.com/lev2gen/watchthis/issues).
